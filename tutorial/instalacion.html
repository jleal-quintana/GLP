Instalación de CapIV en Excel

Necesitás Excel de escritorio, conexión a internet y capiv-installer.zip.

Descargar instalador Abrir guía PDF

Instalar

  1. Descargar y extraer capiv-installer.zip.
  2. Cerrar Excel completamente.
  3. Ejecutar instalar.bat.
  4. Abrir Excel con un libro nuevo.
  5. Ir a Inicio > Complementos > Más complementos > Complementos de desarrollador.
  6. Seleccionar CapIV.
Para desinstalar

Cerrá Excel y ejecutá desinstalar.bat desde la misma carpeta extraída.

Descargar una base

En Datos, elegí áreas y nivel Área o Pozo. Dejá seleccionada Nueva hoja y CapIV creará CapIV_Datos desde A1, sin pedir una celda. Celda actual queda como alternativa. Para incorporar meses nuevos, abrí el mismo Excel y pulsá Actualizar datos.

Pronósticos es opcional y tiene su propio flujo. Genera un pronóstico separado por cada área o concesión seleccionada; Resumen_Areas sólo las reúne para comparar.
